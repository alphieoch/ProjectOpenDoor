# Models

```
GET /v1/models
GET /v1/models/:model
```

`GET /v1/models` lists every model the gateway will advertise for this key: platform providers, org-scoped custom deployments, and BYOK adapters. Rows are enriched with catalog status and list prices when those exist in Postgres.

```bash
export OPENDOOR_API_KEY=opd_…
export OPENDOOR_BASE_URL={{GATEWAY_URL}}

curl "$OPENDOOR_BASE_URL/v1/models" \
  -H "Authorization: Bearer $OPENDOOR_API_KEY"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "{{EXAMPLE_MODEL}}",
      "object": "model",
      "owned_by": "google",
      "provider": "vertex",
      "deployment_status": "live",
      "display_name": "Gemma 4 26B",
      "context_window": 128000,
      "supports_vision": false,
      "supports_tools": true,
      "supports_json_mode": true,
      "pricing": {
        "prompt": 0.15,
        "completion": 0.6
      },
      "architecture": {
        "modality": "text",

```

Pricing numbers are catalog list rates (per 1M tokens in `prompt` / `completion` when present). Always treat `GET /v1/models` as source of truth for your workspace.

## Deployment status

| Status | Meaning | Chat |
|--------|---------|------|
| `live` | Callable now | **200** |
| `warming` | Listed; not serving yet | **503** |
| `dedicated` | Needs a GPU from Dashboard → Deployments | **400** |
| `available_on_request` | Closed / marketplace only (open-weight is not blocked on this flag) | **400** for closed |
| `coming_soon` | Not callable yet | **400** |

Filter to live models:

```bash
curl "$OPENDOOR_BASE_URL/v1/models" \
  -H "Authorization: Bearer $OPENDOOR_API_KEY" \
  | jq '.data | map(select(.deployment_status == "live"))'
```

## One model

```bash
curl "$OPENDOOR_BASE_URL/v1/models/{{EXAMPLE_MODEL}}" \
  -H "Authorization: Bearer $OPENDOOR_API_KEY"
```

Returns `{ id, object, created, owned_by }` for a routed id, or **404** `{ "error": "Model not found" }`.
