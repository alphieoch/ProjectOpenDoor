# Azure Setup

## Prerequisites

- Azure subscription
- Azure CLI installed
- Owner or Contributor access to the subscription

## Create Resources

### 1. Log in

```bash
az login
az account set --subscription "Your Subscription"
```

### 2. Create Resource Group

```bash
az group create \
  --name OchiengandCo \
  --location uksouth
```

### 3. Create Azure OpenAI Account

```bash
az cognitiveservices account create \
  --name ochiengandco-openai \
  --resource-group OchiengandCo \
  --kind OpenAI \
  --sku S0 \
  --location uksouth
```

### 4. Get API Keys

```bash
az cognitiveservices account keys list \
  --name ochiengandco-openai \
  --resource-group OchiengandCo
```

### 5. Deploy Models

```bash
# GPT-4o
az cognitiveservices account deployment create \
  --name ochiengandco-openai --resource-group OchiengandCo \
  --deployment-name gpt-4o \
  --model-name gpt-4o --model-version "2024-11-20" \
  --model-format OpenAI \
  --sku-capacity 1 --sku-name GlobalStandard

# DeepSeek-R1
az cognitiveservices account deployment create \
  --name ochiengandco-openai --resource-group OchiengandCo \
  --deployment-name DeepSeek-R1 \
  --model-name DeepSeek-R1 --model-version "1" \
  --model-format DeepSeek \
  --sku-capacity 1 --sku-name GlobalStandard
```

## Environment Variables

```bash

AZURE_SUBSCRIPTION_ID=your-sub-id
AZURE_RESOURCE_GROUP=OchiengandCo
AZURE_OPENAI_ACCOUNT=ochiengandco-openai
AZURE_REGION=uksouth
```
