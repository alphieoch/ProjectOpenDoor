Keys live in `api_keys`. The raw secret is shown **once** at create time (prefix `opd_`). The dashboard never stores the full key after that — only a hash and prefix.

## Create one

1. Open **Dashboard → API keys**.
2. Name it (for example `Production` or `Playground`).
3. Leave **full access** on, or tick models from the **live catalog** (same list as Models).
4. Copy the secret immediately.

The create response also writes `localStorage.od_playground_api_key` in this browser so **Open playground with this key** works without pasting.

The playground, if it finds no stored key, `POST`s `/api/keys` with the name `Playground` and keeps that secret in the same `localStorage` key.

## Call the gateway

```python
from openai import OpenAI

client = OpenAI(
  base_url="http://localhost:3001/v1",  # or your deployed gateway
  api_key="YOUR_OPENDOOR_KEY",
)
r = client.chat.completions.create(
  model="YOUR_MODEL_ID",
  messages=[{"role": "user", "content": "Hello"}],
)
```

`base_url` must be the **gateway**, not the dashboard. Overview copies this snippet with `NEXT_PUBLIC_GATEWAY_URL` and the first enabled catalog model id.

## Limits that are real

- **Allowed models** — if you restricted the key, other ids 403
- **RPM / TPM** — per-key rate limits
- **Spend** — optional cents cap on the key; org credits and plan budget still apply

Revoke from the same page. Revoked keys fail auth immediately.
